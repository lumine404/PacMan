# PacMan

A Pac-Man game developed in Java using Swing and AWT.

## About

This project is a recreation of the classic Pac-Man arcade game.

It was built to practice Java programming, object-oriented programming concepts, and GUI development while gradually implementing the game's mechanics.

## Technologies

- Java
- Java Swing
- Java AWT

## Controls

| Key | Action |
|---|---|
| ↑ | Move up |
| ↓ | Move down |
| ← | Move left |
| → | Move right |

## Features

- Game board generated using a tile map.
- Player movement and directional sprites.
- Basic random ghost movement.
- Wall collision detection.
- Collectible pellets.
- Score tracking.
- Three lives.
- Game Over and restart functionality.

## What I Learned

- **Java Swing:** `JFrame`, `JPanel`, `Timer`, and `ImageIcon`.
- **AWT Graphics:** Drawing images, rectangles, and text.
- **Event Handling:** `ActionListener` and `KeyListener`.
- **Game Loop:** Updating the game and repainting the screen using a Swing Timer.
- **Tile Maps:** Representing a game board using characters.
- **Collections:** Using `HashSet` to store game objects.
- **Random:** Generating random ghost directions.
- **OOP:** Creating a `Block` class with properties and methods.
- **Movement:** Working with coordinates, directions, and velocity.
- **Collision Detection:** Checking overlaps between game objects.
- **Game State:** Managing score, lives, and the Game Over state.

## How to Run

1. Clone this repository.
2. Open the project in your IDE.
3. Make sure the image assets are available on the classpath.
4. Run `App.java`.
